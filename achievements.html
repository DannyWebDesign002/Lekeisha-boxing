📋 Edit Fight Record

How to edit fight record: Open index.html in a text editor, find the FIGHT_RECORD array in the JavaScript section near the bottom. Add or edit entries following the same format. Each entry has: date, opponent, country, result, method, event, location, weight.

🚀 Deployment Guide & Folder Structure

Recommended folder structure for production:
lekeishapergoliti.com.au/
├── index.html           ← Home page
├── achievements.html  ← Fight record, achievements & world map
├── robots.txt           ← SEO: disallow /admin
├── sitemap.xml          ← SEO: auto-generated
├── .htaccess            ← Security headers (Apache)
├── images/
│   ├── hero.jpg         ← Main hero photo
│   ├── gallery/         ← Fight + training photos
│   └── og-image.jpg  ← Social share image (1200×630)
├── assets/
│   ├── fonts/           ← Self-hosted fonts (optional)
│   └── favicon.ico
└── api/                 ← PHP/Node contact form backend
     └── contact.php

// Security headers (.htaccess)
Header set X-Frame-Options "SAMEORIGIN"
Header set X-Content-Type-Options "nosniff"
Header set Referrer-Policy "strict-origin-when-cross-origin"
Header set Permissions-Policy "camera=(), microphone=()"
Header always set Strict-Transport-Security "max-age=31536000"
RewriteEngine On
RewriteCond %{HTTPS} off
RewriteRule ^ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
Contact form backend (contact.php): Create a PHP file that validates POST data, applies rate limiting by IP, sanitises all inputs, and sends email via PHPMailer. Never expose API keys in frontend code. Use environment variables for SMTP credentials.
Hosting recommendation: SiteGround or WP Engine (Australia region) for Australian SEO advantage. Enable Cloudflare CDN for performance and DDoS protection. Use Let's Encrypt for free SSL.
